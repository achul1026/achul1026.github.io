# 김경철의 백엔드 노트

https://achul1026.github.io

GitHub Pages(Jekyll) 블로그입니다. 편집 계획과 규칙은 [`docs/EDITORIAL.md`](docs/EDITORIAL.md).

## 글 올리는 법
- 새 글: `_posts/YYYY-MM-DD-제목.md` (날짜가 아직 안 온 글은 그 날짜에 자동 게시)
- 작성 중인 글: `_drafts/` (게시되지 않음)
- 이미지: `assets/images/`

## 승인
초안은 Pull Request로 올라옵니다. 내용을 읽고 **Merge** 하면 승인이고, 글 날짜가 되면 게시됩니다. (휴대폰의 GitHub 앱에서도 Merge 할 수 있습니다.)
